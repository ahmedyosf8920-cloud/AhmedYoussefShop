بناء نسخة الويندوز والأندرويد من نفس البرنامج (مرة واحدة)
=========================================================

ملاحظة صادقة: جهّزت المشروع وفحصت كود البرنامج نفسه، لكن لم أستطع بناء ملفي exe/apk من هنا (لا يوجد إنترنت في بيئتي)،
فلم تُختبر النسخ المبنية على جهاز حقيقي. جرّب أول نسخة وأخبرني بأي مشكلة لأصلحها.

الطريقة الأسهل: GitHub (عندك حساب بالفعل ويُستضاف عليه البرنامج)
------------------------------------------------------------------
1) فك الضغط، وارفع كل محتويات المجلد إلى المستودع (repository) بدل الملفات القديمة
   (بما فيها مجلد .github — يفضّل الرفع بـ GitHub Desktop أو git حتى لا يُهمل المجلد المخفي).
   موقعك على GitHub Pages سيستمر في العمل لأن index.html في الجذر كما كان.
2) من صفحة المستودع: تبويب Actions ← «بناء تطبيقات الويندوز والأندرويد» ← Run workflow.
3) بعد 10–15 دقيقة افتح التشغيلة، ومن أسفل الصفحة (Artifacts) حمّل:
   • windows-app  ← ملف التثبيت AhmedYoussefCentral-...-win.exe + نسخة محمولة (Portable)
   • android-app  ← AhmedYoussefCentral-android.apk
   ولاحقًا كلما حدّثت الملفات شغّل Run workflow مرة أخرى فقط.

بالطريقة اليدوية على ويندوز
---------------------------
ثبّت Node.js (نسخة LTS) من nodejs.org ثم اضغط مرتين على build-windows.bat — يظهر الملف في مجلد dist.
(أول مرة يحتاج إنترنت لتحميل المكتبات، وبعدها يعمل البرنامج نفسه بدون إنترنت.)

الأندرويد يدويًا: ثبّت Android Studio + JDK 17، ثم:
  npm install
  npm run android:init
  ثم افتح مجلد android في Android Studio ← Build ← Build APK.
(الـ APK يُوقَّع تجريبيًا — للتثبيت اسمح بـ «التثبيت من مصادر غير معروفة». للنشر على Play Store يلزم توقيع إصدار.)

ماذا يعمل بدون إنترنت؟
----------------------
- كل البرنامج (بيع، صيانة، عملاء، تقارير...) يعمل من الجهاز؛ والبيانات تُحفظ محليًا، وتتزامن مع السحابة عند تسجيل الدخول لاحقًا (مع دمج آمن).
- المكتبات (Supabase وExcel) تُضمَّن داخل التطبيق أثناء البناء فلا تحتاج إنترنت.
- يحتاج إنترنت فقط: المزامنة السحابية، تحميل التلاوات لأول مرة، قوائم القراء، رسائل واتساب.

فروق النسخ
----------
ويندوز: يبقى في شريط المهام بعد الإغلاق (لتعمل مواقيت الصلاة والأذان)، ويمكن تشغيله مع ويندوز من قائمة الأيقونة. تحديد الموقع GPS غير متاح — اختر المدينة يدويًا. الطباعة تعمل عادي.
أندرويد: إشعارات الصلاة تُجدول بنظام الأندرويد نفسه (تعمل والتطبيق مغلق، وتُعاد بعد إعادة التشغيل). النسخ الاحتياطي والتصدير يُحفظ/يُشارك من نافذة المشاركة. طباعة الفواتير من داخل التطبيق غير مدعومة في أندرويد حاليًا — استخدم المشاركة أو نسخة الويندوز للطباعة.
  صوت الأذان الكامل أثناء إغلاق التطبيق غير مُضمَّن (يُستخدم صوت الإشعار الافتراضي) لعدم وجود ملف أذان محلي لدي؛ يمكن إضافته لاحقًا.
